# BitchRella - Features Pack
This local build adds:
- Groups and Contacts (existing)
- Favorites
- Emoji picker
- Reply to messages
- Edit/Delete own messages
- Image/file upload (15 MB, common formats)
- Read receipts and typing (existing)
- Dark Mode
- Settings window
- Remember me on login
- Forgot-password placeholder for the later online email service

Run server first:
`python -m uvicorn server.main:app --reload`
Then app:
`python main.py`
